### 1. URL Shortener + Click Analytics

A backend-focused web application built with Flask and PostgreSQL for URL shortening, fast redirects, asynchronous click-event processing, and per-link analytics.

**Key features**
- Unique Base62 short-code generation backed by PostgreSQL sequences
- Redis caching for faster URL redirects
- Asynchronous click-event processing using Redis Queue (RQ)

- URL lifecycle management, including custom aliases, expiration, deactivation/reactivation, and QR code generation
